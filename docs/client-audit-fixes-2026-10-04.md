# Исправления аудита iOS клиента Quizice

В этом проходе изменён только iOS-клиент. Backend и админка находятся вне согласованной области работ. Временно внесённые нами изменения четырёх backend-файлов удалены по просьбе пользователя; чужие материалы аудита сохранены. Новые продуктовые возможности — покупки, офлайн-загрузка тем и управление аккаунтом — отложены.

## Исправления клиента

| Область | Итог |
|---|---|
| Статистика нулевого результата | Клиент принимает подтверждённый сервером результат с legacy best 0/0 только при полностью нулевом числе правильных ответов. Очередь очищается; противоречивые ответы и отсутствующие подтверждения отвергаются. |
| AI контракт | Непустое объяснение до 2000 символов принимается согласно действующему API. Месячная квота отличается от временного 429; интерфейс не предлагает бесполезный немедленный повтор. |
| Состояние игры | Раунд хранит собственную копию вопросов и метаданных. Обновление каталога и избранного не очищает текущий выбор; повтор использует завершённый раунд. |
| Аккаунты | Авторизация нового игрока отменяет старую синхронизацию и сбрасывает активного владельца статистики. Ответы старых запросов не меняют состояние нового игрока. |
| Избранное | Хранение разделено по аккаунту и языку; ответы запросов сверяются с владельцем и ревизией. Новое гостевое предпочтение переносится один раз; неоднозначные legacy-данные не присваиваются аккаунту. Общий кэш каталога не сохраняет персональные отметки. |
| Ошибки запуска | Ошибка показывается поверх раскрытой карточки с повтором и возвратом. Пустая выдача не открывает пустой игровой экран и не блокирует карточку. |
| Таймер и доступность | Время считается по монотонным часам; задержка main thread не дарит дополнительное время. Фон приостанавливает игру. Повтор корректно восстанавливает таймер после изменения VoiceOver. Смена оформления сохраняет подсветку ответа. |
| Запуск приложения | Ожидание первоначального обновления ограничено тремя секундами; после него доступен локальный экран и сохраняется показ онбординга. |
| Аналитика | Событие начала игры формируется в presenter после загрузки вопросов, включая повтор. В нём указано фактическое число вопросов. |
| Хранение | Замена SwiftData-каталога выполняется одним сохранением с rollback при ошибке. Повреждённая очередь ответов сохраняется отдельно и больше не блокирует новые записи. Неотправленные авторизованные события не обрезаются. |
| Диагностика и тесты | Dev-auth заголовок скрыт в Pulse. XCTest получает отдельную очередь без живого API, Keychain и фонового мониторинга. |
| Выпуск | Release требует корректный HTTPS адрес backend. Аналитика остаётся необязательной. Добавлен Release CI job; live-проверки используют один согласованный origin для API и health. |
| Контент | Удалены точные дубликаты из bundled-каталога; исправлены найденные формулировки Satisfaction и эксперимента с базовым доходом. В каждой локали 374 вопроса. Полная фактологическая проверка каталога не выполнялась. |
| Ограничения продукта | Фильтры повторов недоступны гостю и bundled-каталогу с пояснением. Для встроенных вопросов скрыт неподдерживаемый выбор сложности; локальный результат не получает выдуманную сложность. Экран подписки сообщает о недоступности покупок; покупка и восстановление скрыты, цена и обещания неработающих платных преимуществ удалены. |

## Совместимость с backend

Клиент использует существующие поля API. Предположения о новых answer ID и покомпонентных ответах синхронизации удалены. Существующее разделение отклонённого пакета ответов изолирует непринимаемые события и сохраняет остальные.

Неполный раунд больше не обрезается до ближайших 5/10/15 вопросов. Его результат сохраняется локально. Пока серверный контракт статистики поддерживает только 5/10/15, остальные размеры остаются в localOnly и не блокируют очередь обычных партий. Автоматическая отправка таких результатов потребует подтверждённой поддержки backend.

Серверное вычисление best 0/0, оценка старых ответов после правки переводов, история версий, миграции, дедупликация серверного каталога, квоты и эксплуатация backend остаются работой отдельного агента. Клиентские изменения не заменяют эти исправления.

## Privacy manifest

Manifest дополнен связанными с пользователем идентификаторами, игровым содержимым и свободным текстом AI-темы для работы приложения. Это отражает существующие запросы авторизации, прогресса и генерации. Названия категорий сверены с [документацией Apple](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacycollecteddatatypes/nsprivacycollecteddatatype). App Store Connect и политика хранения данных на сервере этим изменением не настраиваются.

Итого 585 XCTest: 582 прошли, 3 проверки живого backend явно пропущены. UI contracts создают контроллеры и представления внутри XCTest; это не сквозной XCUITest с Game Center и рабочим сервером.

Визуально просмотрены и обновлены 16 эталонов: экраны и баннеры подписки, настройки, Home и карточки встроенных тем. Проверка выявила и устранила перекрытие текста нижней панелью при крупном шрифте и узкую колонку пояснения повторов. Окончательный snapshot-прогон выполнялся с отключённой записью эталонов. Новая UI-проверка также покрывает переиспользование карточки backend → bundled → backend, доступность и отсутствие действий у скрытого выбора сложности.

Результаты и покрытие сохранены в [объединённом xcresult](../DerivedData/Audit-2026-10-04/ClientFixes/combined.xcresult). Подписанный archive, установка из App Store, живые Game Center / AI / backend и сквозная staging-проверка в этот проход не входили. В сборке остаются предупреждения SwiftLint и о будущих требованиях изоляции Swift 6.
