# Quizice

## Названия pull request

- Каждый новый PR должен начинаться с версии целевого релиза: `Quizice <версия>: <описание>`.
- Текущая целевая версия новых PR — **1.1**. Используй префикс `Quizice 1.1:` сейчас и после публикации релиза 1.0 в App Store.
- Сохраняй этот префикс, пока пользователь или согласованный план релиза явно не задаст следующую целевую версию. Сам выход релиза в App Store не повод автоматически увеличивать номер.
- Если пользователь явно указывает другую целевую версию для конкретного PR, используй её. При создании или переименовании PR проверяй наличие префикса.
